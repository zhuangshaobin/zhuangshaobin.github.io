# Project-page fonts

Geist Sans and Geist Mono are by the [Geist Project](https://github.com/vercel/geist-font).
Both fonts are distributed under the SIL Open Font License 1.1; the original
license files are included alongside the binaries.

These are unmodified Latin variable WOFF2 files (weights 100–900), downloaded
from Google Fonts on 2026-11-22 and served locally. Text outside the Latin subset
uses the system font fallback. The page makes no requests to a font CDN.
